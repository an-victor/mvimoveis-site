# Source Tree: Design System Orchestration

A estrutura do squad reflete a Arquitetura Atômica e os Playbooks dos especialistas.

```text
./squads/design-system-orchestration/
├── squad.yaml              # Manifesto central
├── agents/                 # Especialistas (Architect, Strategist, etc.)
├── tasks/                  # Playbooks técnicos e fluxos de trabalho
├── config/                 # Padrões, tech stack e estrutura
├── scripts/                # Scripts de validação e automação de tokens
├── checklists/             # Listas de auditoria heurística e acessibilidade
└── templates/              # Blueprints de prompts e componentes
```
