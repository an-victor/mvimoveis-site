# Coding Standards: Design System Orchestration

Este squad segue os padrões de Design Ops e Arquitetura Atômica.

## Princípios
1. **Task-First:** Toda ação deve ser uma tarefa documentada.
2. **Token-Driven:** Nenhuma cor ou espaçamento deve ser "mágico" (hardcoded).
3. **Accessibility-First:** Contraste e acessibilidade são pré-requisitos, não opcionais.
4. **Regra de Três:** Só abstraia componentes usados por 3 ou mais produtos.

## Nomenclatura
- **Tokens Semânticos:** `color-action-primary`, `spacing-layout-medium`.
- **Componentes:** Kebab-case (`primary-button`, `main-nav`).
