# Story 1.1: Unificação de Layout Global

## 📝 Descrição da Story
Mover as implementações duplicadas de Header e Footer das páginas individuais para o `layout.tsx` raiz do Next.js. Isso garantirá consistência visual em todo o site, melhorará a performance de navegação e facilitará a manutenção futura.

## 🎯 Critérios de Aceitação
- [x] O componente `Header` deve ser extraído para `components/header.tsx`.
- [x] O componente `Footer` deve ser extraído para `components/footer.tsx`.
- [x] O `app/layout.tsx` deve renderizar o `Header` e o `Footer` globalmente.
- [x] As páginas `app/page.tsx` e `app/imoveis/page.tsx` não devem conter código de Header ou Footer.
- [x] A navegação entre a Home e a página de Imóveis deve manter o Header e Footer persistentes (sem re-renderização total).
- [x] O Header deve ser adaptativo (transparente na Home sobre o banner, fixo/branco na listagem de imóveis).
