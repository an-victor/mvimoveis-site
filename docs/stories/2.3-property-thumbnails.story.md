# Story 2.3: Adicionar Thumbnails na Listagem de Imóveis do Dashboard

## Descrição
Como administrador do sistema, quero ver uma thumbnail (miniatura) das imagens dos imóveis na listagem de "Gerenciar Imóveis" do dashboard, para que eu possa identificar facilmente qual imóvel estou editando ou apagando.

## Acceptance Criteria
- [x] A consulta de imóveis do dashboard deve incluir o array de imagens (`images`).
- [x] A tabela de propriedades no dashboard deve ter uma nova coluna para `Imagem`.
- [x] A imagem deve ser renderizada usando a função auxiliar `getImageUrl` ou a tag `<img>` com `src` e `alt` apropriados.
- [x] Se o imóvel não tiver imagem, deve exibir uma imagem placeholder genérica ou ficar em branco/com um ícone padrão.
- [x] O layout da tabela deve acomodar a nova coluna de imagem de forma responsiva.

## Tasks
- [x] Atualizar `DASHBOARD_PROPERTIES_QUERY` no arquivo `app/dashboard/properties/page.tsx` para incluir o campo `images`.
- [x] Implementar a renderização da imagem na `TableRow` em `app/dashboard/properties/page.tsx`.
