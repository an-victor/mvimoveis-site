# Story 2.4: Otimização de Core Web Vitals (Imagens)

## Descrição
Como desenvolvedor, quero melhorar a performance do site (LCP e Cumulative Layout Shift) implementando as melhores práticas do Next.js para imagens, aprimorando as pontuações no Google PageSpeed Insights.

## Acceptance Criteria
- [x] O arquivo `next.config.mjs` deve permitir imagens otimizadas do Sanity via `remotePatterns`.
- [x] O arquivo `next.config.mjs` NÃO deve definir `unoptimized: true`.
- [x] A tag `<img>` no `PropertyCard` deve ser substituída por `<Image>` do `next/image` com o atributo `fill` ou dimensões explícitas.
- [x] Onde houver imagens principais/LCP (como Banners ou Primeiros itens da lista), a tag `<Image>` deve usar o atributo `priority`.
- [x] A galeria e outros componentes chave devem utilizar o `<Image>` no lugar da tag nativa ou passar dimensões, sempre que aplicável.

## Tasks
- [x] Ajustar propriedades em `next.config.mjs`.
- [x] Refatorar imagens no card de propriedades (`components/property-card.tsx`).
- [x] Refatorar imagens do banner carrossel (`components/banner-carousel.tsx`) e adicionar prop de `priority`.
- [x] Refatorar galeria (`components/property-gallery.tsx`).
