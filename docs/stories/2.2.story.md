# Story 8.1: Captura de Leads e Exibição de Mídia Dinâmica

## 📝 Descrição da Story
Integrar o Supabase para captura de leads e melhorar a exibição de mídias na página de detalhes do imóvel. O objetivo é coletar dados básicos do usuário (Nome, Telefone) antes do redirecionamento para o WhatsApp, garantindo uma base de leads para o corretor e uma melhor experiência visual com mapa e tour 360°.

## 🎯 Critérios de Aceitação
- [x] Implementar modal de captura de Nome e WhatsApp antes do botão do WhatsApp.
- [x] Criar tabela `leads` no Supabase e salvar os dados via Server Actions.
- [x] Adicionar aba de visualização dos leads no Dashboard Administrativo.
- [x] Adicionar aba de "Localização" com embed do Google Maps.
- [x] Adicionar aba de "Tour Virtual" com embed do link cadastrado.
- [x] Garantir que as abas de mídia só apareçam se os links correspondentes existirem no Sanity.

## 🛠️ Tarefas / Subtarefas
- [x] **Task 1: Setup Supabase**
    - Configurado cliente `supabase-js` em `lib/supabase.ts` usando chaves de ambiente.
- [x] **Task 2: Implementar Captura de Leads**
    - Criado `LeadCaptureButton` e a Server Action `saveLead`.
- [x] **Task 3: Dashboard de Leads**
    - Criada a página `app/dashboard/leads/page.tsx` com listagem em tabela.
- [x] **Task 4: Enriquecer Página do Imóvel**
    - Refatorado o uso de Tabs em `app/imoveis/[slug]/page.tsx` para incluir Mapa e Tour Virtual dinâmicos.

## 📝 Dev Agent Record
- **Completion Notes**: Captura de leads agora é obrigatória antes do contato via WhatsApp, fornecendo dados valiosos para o corretor. As abas de mídia dinâmicas aumentam significativamente a qualidade visual do anúncio.
- **Challenges Encountered**: A integração do Supabase foi feita usando Service Role no lado do servidor para simplificar a inserção direta.
